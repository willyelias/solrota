# Changelog

## [1.0.0] - 2026-06-18

### ✨ Inicial

**Funcionalidades principais:**
- Quiz interativo com 5 passos
- Seleção de hotel com autocomplete (60+ opções)
- Definição de grupo e quantidade de pessoas
- Seleção de dias e período
- Escolha de estilo (relaxar, aventura, cultura, gastronomia, noturno, romântico)
- Refeições automáticas e personalizáveis
- Mapa interativo com Leaflet
- Timeline detalhada com dicas locais
- Estimativa de custos
- Chat para ajustes (mockado)

**Roteiros:**
- Natal (3 períodos + dia inteiro)
- Pipa (3 períodos + dia inteiro)
- Genipabu (3 períodos + dia inteiro)

**Design:**
- Mobile-first responsivo
- Paleta: Laranja (#F5A623), Azul (#0A7EA4), Bege (#FDF6EC)
- Tipografia: Syne + Inter
- Animações e transições suaves

**Estrutura:**
- index.html (HTML + CSS inline)
- assets/js/script.js (JavaScript puro)
- README.md completo
- .gitignore
- CHANGELOG.md
