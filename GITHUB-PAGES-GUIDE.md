# 🌐 Guia: Como Ativar GitHub Pages

## ✅ Passo a Passo para Ativar o Site Online

### 1️⃣ Acesse o Repositório
Vá em: **https://github.com/willyelias/solrota**

### 2️⃣ Vá para Settings (Configurações)
- Clique na aba **Settings** (engrenagem)
- No menu à esquerda, procure por **Pages**

### 3️⃣ Configure o GitHub Pages
Na seção "Build and deployment":
- **Source**: Selecione **Deploy from a branch**
- **Branch**: Selecione **main** (e deixe **/root** selecionado)
- Clique em **Save**

### 4️⃣ Aguarde o Deploy
- GitHub vai processar por ~1-2 minutos
- Você verá uma mensagem azul: "✓ Your site is live at..."

### 5️⃣ Acesse o Site
Seu site estará em: **https://willyelias.github.io/solrota**

## 🔧 Se der erro

**Problema:** Site não carrega  
**Solução:** 
- Aguarde 5 minutos (deploy demora)
- Faça F5 para recarregar
- Verifique se Branch está em **main**

**Problema:** CSS/JavaScript não está carregando  
**Solução:**
- Certifique-se que todos os arquivos estão no repositório:
  - ✅ `index.html`
  - ✅ `assets/css/styles.css`
  - ✅ `assets/js/script.js`
